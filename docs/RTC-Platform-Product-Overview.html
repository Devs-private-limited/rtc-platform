RTC Platform

Product & Technical Overview

Version: 1.0 Date: August 2026 Status: Core platform complete

RTC Platform is an embeddable real-time communication service inspired by Zego and Agora. Any product can add 1:1 chat, voice calls, and group voice by integrating a single JavaScript SDK — without building WebRTC infrastructure from scratch.

1. Executive Summary

Customers integrate @rtc/sdk into their web or mobile apps. The platform handles signaling, authentication, room management, media routing (P2P or SFU), and TURN relay for cross-network connectivity.

What is built today

  • Signaling server (WebSocket + REST) with multi-tenant app registry
  • mediasoup SFU for 1:1 and group voice
  • Publishable SDK (ESM + CJS + TypeScript types)
  • Live two-panel demo application
  • Redis-backed signaling scale-out
  • PostgreSQL app credentials store
  • coturn TURN server for NAT traversal

2. Vision — What We Want to Build

2.1 Problem

Building real-time voice and chat in-house requires WebRTC expertise, signaling, media servers, TURN relays, auth, scaling, and maintenance. Most teams want to add a voice room in a day — not a six-month RTC project.

3. How It Works

3.1 Architecture

6. Security Model

  • App Secret — bcrypt-hashed in PostgreSQL; server-side only
  • User Token — Short-lived JWT (appId + userId)
  • WebSocket — Requires valid token; actions tied to authenticated user
  • Admin API — Separate ADMIN_API_KEY for app registration

8. Integration Example

import { RTCExpress } from "@rtc/sdk";

// Server-side only
const { token } = await RTCExpress.fetchToken("https://signal.example.com", {
  appId: "your-app-id",
  appSecret: process.env.RTC_APP_SECRET,
  userId: "user_123",
});

// Client-side
const rtc = new RTCExpress();
await rtc.init({
  serverUrl: "https://signal.example.com",
  appId: "your-app-id",
  userId: "user_123",
  token,
  mediaMode: "auto",
});

rtc.on("message", ({ fromUserId, text }) => console.log(fromUserId, text));
rtc.on("callInvite", ({ fromUserId }) => showIncomingCallUI(fromUserId));

await rtc.joinRoom("support-42");
rtc.sendMessage("Hello!");
await rtc.callUser("agent_7");
await rtc.joinVoiceRoom();
