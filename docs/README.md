# RTC Platform — Shareable docs

## Easiest way to share (PDF)

1. Open **`RTC-Platform-Product-Overview.html`** in Chrome or Edge (double-click the file).
2. Press **Ctrl + P** (Print).
3. Choose **Save as PDF** as the destination.
4. Send the PDF to your contact.

The HTML is styled for print — tables and diagrams stay readable in the PDF.

## Other options

| Format | File | Best for |
|--------|------|----------|
| **PDF** | Print from HTML (above) | Email, WhatsApp, formal sharing |
| **HTML** | `RTC-Platform-Product-Overview.html` | Open in any browser; looks polished |
| **Markdown** | `RTC-Platform-Product-Overview.md` | GitHub, developers, editing |
